RadonOS, is a simple OS maked in Assembly and C
with a fast RAMFS system and simple terminal
the OS size is 16kb you can download it here:

About OS:

RadonOS uses VESA Graphics and Protected Mode, and only works with BIOS. The OS uses a kernel made by me, a bootloader made by my friend Cabrito, and a FileSystem made by me. This is a non-profit hobby project, the OS dont will have GUI only TUI OS is inspired by Linux. The source code is available on GitHub

Cabrito:

Made the bootloader initialize in Protected Mode and VESA Graphics. He helped me with the whole OS. Here is his GitHub: Cabrit
